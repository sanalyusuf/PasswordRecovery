# PasswordRecovery

PasswordRecovery şifre kırmaz bilgisayar içerisinde varolan şifreleri okur.

## Gereksinim

- Windows 10/11, 64 bit
- .NET 10 Desktop Runtime (x64)


Kontrol: dotnet --list-runtimes


Şu satır olmalı: Microsoft.WindowsDesktop.App 10.0.x


Yoksa: https://dotnet.microsoft.com/download/dotnet/10.0

## Kullanım

1. Runtime kur.
2. PasswordRecovery.exe çalıştır.
3. Deneme kutusu → fareni şifre satırına getir.
4. Kaydet veya görüntüle.

**Tarayıcıda çalışmaz.**
